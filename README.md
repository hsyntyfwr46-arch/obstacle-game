# لعبة تجاوز العقبات (Obstacle Avoidance Game)
**تم التطوير بواسطة: حسين**

## نظرة عامة على التطبيق
تطبيق لعبة تفاعلي ممتع يعتمد على الويب، حيث يتحكم اللاعب في حركة الكرة لتفادي العقبات الساقطة وتحقيق أعلى النقاط.

## التقنيات المستخدمة
- HTML5 Canvas
- JavaScript
- CSS3
- PHP Development Server

## كيفية تشغيل التطبيق محلياً
